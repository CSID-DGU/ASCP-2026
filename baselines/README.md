# Baselines

기존 방법과의 비교 및 재평가 코드를 모아둔 진입점임.

- `baselines/eval_vs_baseline.py`: RL과 baseline 직접 비교
- `Tahir`: `RL/baseline/Tahir` 원본 링크
- `zeren`: `RL/baseline/zeren` 원본 링크

`RL/baseline/`은 loader와 기존 import가 연결된 원본 위치이므로 이동하지 않음.
이 폴더에서는 링크를 통해 baseline 관련 코드를 한곳에서 찾음.

논문 실험별 실행 목록:

- 기존 AAAI: `paper_experiments/AAAI/06_baselines/`
- 신규 저널: `paper_experiments/journal/06_baselines/`
